Lista de pares etiqueta/valor en mono 13px. Cada fila lleva una línea superior.

**Props:** `items` (`label`, `value`, `accent?`), `className`.

**Reglas**
- Etiqueta en `text-muted`, valor en `text`.
- `accent` solo para un valor por lista (por ejemplo, la estrategia de render).
- Va dentro de un `Panel`.
