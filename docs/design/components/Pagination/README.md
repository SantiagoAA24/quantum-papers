Navegación entre páginas de resultados con enlaces "anterior" y "siguiente".

**Props:** `pages` (`label`, `href`, `current`, `gap`), `prevHref`, `nextHref`, `className`.

**Reglas**
- Objetivos de 44px; la página actual usa borde y texto en acento y `aria-current="page"`.
- Los huecos se dibujan como `…` y se ocultan a lectores de pantalla.
