Tag de tema que se muestra como hashtag en mono ("#vqc") y enlaza a la página del tema.

**Props:** `label` (sin el `#`), `href`.

**Reglas**
- Etiquetas en minúsculas y con guiones: `#barren-plateaus`, `#corrección-de-errores`.
- Fondo `bg-tag`, borde `border`, radio `radius-md`, alto `control-md`.
- Al pasar el cursor, el fondo sube a `bg-panel`.
- Van en una fila que envuelve, con `space-3` entre ellos.
