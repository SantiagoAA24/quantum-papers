Campo de texto con etiqueta visible encima.

**Props:** `label`, `id`, `type`, `name`, `defaultValue`, `placeholder`, `onChange`, `className`.

**Reglas**
- La etiqueta siempre es visible; el placeholder no la reemplaza.
- Alto `control-md` (48px), fondo `bg-panel`, radio `radius-md`.
- El borde `border` es decorativo (contraste bajo): el foco añade un contorno de 2px en `text`.
