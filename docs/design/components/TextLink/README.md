Enlace de texto en `accent`, en mono de 14px (`mono-nav`), para acciones secundarias como "ver_todos →".

**Props:** `href`, `children`.

**Reglas**
- Etiqueta en minúsculas con guion bajo y flecha `→` al final.
- Alto mínimo `touch-min`; subrayado al pasar el cursor.
- Se alinea a la derecha del título de su sección.
