Casilla con etiqueta en mono 15px. Toda la fila es el área de clic.

**Props:** `name`, `value`, `defaultChecked`, `disabled`, `onChange`, `className`, `children`.

**Reglas**
- Alto mínimo `touch-min` (44px).
- La casilla usa el acento; el foco muestra un contorno de 2px en `text`.
- Agrúpalas dentro de un `FilterGroup`.
