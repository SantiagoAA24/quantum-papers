# Pantallas de diseño

Fuente de las pantallas (archivos `.dc.html` de Claude Design). Son la referencia visual para las fases 2 a 8:

- `home/`: home. La opción elegida es `B-Laboratorio.dc.html`.
- `pantallas/`: detalle de paper (`Main`), búsqueda, carga con esqueletos, how-it-works, about y paleta ⌘K.
- `estados/`: sin resultados (`Main`), error 503 y 404.
- `movil/`: versión de 390 px (home, menú, búsqueda, filtros, detalle).

Se abren y se ven renderizadas en Claude Design con el sistema de diseño «QuantumPapers». Este repositorio no incluye capturas PNG: expórtalas desde Claude Design a esta carpeta si quieres que Claude Code las compare visualmente.
